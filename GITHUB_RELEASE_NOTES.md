# DATA301 ML Studio v4.0 — Cosmic Course Experience

This release graduates DATA301 ML Studio from an interactive course prototype into a complete Vidyashilp University learning environment.

- Course Overview is now the first academic entry point.
- Module 2 is deeply integrated from the supplied 110-slide supervised-learning deck rather than exposed as a detached download.

- All twelve browser-based interactive Labs remain part of the platform and now connect contextually to Module 2.

- The Detailed Course Plan is staff-only, while the Course Overview, Module 1, and Module 2 are delivered publicly through short-lived signed links from private Supabase Storage.
- The visual system now uses a richer VU campus identity, atmospheric motion, stronger course storytelling, and expanded responsive behavior.
- Dr. Shabbeer Basha receives a separately provisioned administrator account with a required first-login password change.
- A discreet, discoverable credit identifies Krishna V Gowda as platform designer and developer.
- Release automation now uses a verified preview-first Vercel promotion path, full source/security checks, Supabase verification, and live route/material smoke tests.
