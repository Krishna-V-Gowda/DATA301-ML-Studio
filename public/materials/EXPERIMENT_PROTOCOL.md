# Machine-learning experiment protocol

1. State a falsifiable hypothesis.
2. Freeze train/validation/test boundaries before comparing models.
3. Define the metric and baseline.
4. Record preprocessing inside the fitted pipeline.
5. Check leakage, class imbalance, and calibration where relevant.
6. Retain the seed, dependency versions, configuration, and raw results.
7. Report failures and uncertainty, not only the best run.
