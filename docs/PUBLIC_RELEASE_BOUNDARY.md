# Public release boundary

The source supplied for portfolio engineering included institution-specific branding, named instructor metadata, private delivery notes, email/walkthrough drafts, and course PDF/DOCX binaries.

The public edition deliberately:

- replaces the institution logo with an original DATA301 mark;
- changes named institution/instructor metadata to independent reference metadata;
- removes private handoff and launch documents;
- removes all supplied PDF/DOCX course files and their thumbnails;
- retains only author-created Markdown fallback resources;
- preserves the generic secure educator workflow and relational/RLS design.

This sanitization does not claim institutional endorsement or ownership of the removed materials. The private source snapshot is not included in the public repository package.
