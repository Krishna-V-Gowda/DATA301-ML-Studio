# Product strategy — DATA301 ML Studio V4

## Product thesis

A course website should not merely distribute files. It should help a learner understand where a concept sits, why it exists, how it behaves, how the mathematics describes it, how to implement it, and how to judge its output.

## Defining experience

```text
Course context
  → concept intuition
  → interactive behaviour
  → mathematics
  → implementation path
  → evaluation
  → related concept / next step
```

## Signature advantages

1. **Twelve inspectable laboratories** rather than decorative algorithm cards.
2. **Course-connected learning architecture** rather than isolated pages.
3. **Module 2 presentation-to-lab mapping** rather than a detached download.
4. **Instructor-managed private content** rather than source-code edits for every class.
5. **Authentic VU identity** without falling back to a generic university template.
6. **Clear authorship boundaries** between platform engineering and academic material.

## Quality standard

Every feature must improve at least one of:

- conceptual understanding;
- navigation and continuity;
- academic accuracy;
- instructor maintainability;
- accessibility;
- performance;
- trustworthy presentation.

Features that merely increase count or visual noise are excluded.
